# Desafio Power BI — Relatório de Vendas

## Sobre o projeto

Projeto desenvolvido como parte do desafio da **DIO (Digital Innovation One)**, com o objetivo de aprimorar um relatório de vendas utilizando o Microsoft Power BI.

O relatório foi construído a partir da base de dados **Financial Sample**, permitindo analisar o desempenho de vendas, faturamento, lucratividade e distribuição geográfica dos resultados.

## Objetivos

- Desenvolver um relatório interativo e visualmente organizado.
- Analisar vendas e lucros por país e segmento.
- Criar indicadores financeiros para acompanhamento de resultados.
- Implementar filtros dinâmicos e sincronizados.
- Utilizar botões, indicadores e navegação entre páginas.

## Páginas do relatório

Apresenta os principais indicadores financeiros, incluindo faturamento total, lucro total e unidades vendidas, além da comparação das vendas entre países.

### 3. Análise Geográfica e Segmentos

Apresenta a distribuição geográfica dos resultados por meio de mapas e uma análise da participação dos segmentos.

## 🛠️ Ferramentas utilizadas

- Microsoft Power BI Desktop
- Power Query
- Financial Sample (base de dados)
- GitHub

## Funcionalidades implementadas

- Navegação entre três páginas.
- Segmentadores de ano, país e produto.
- Sincronização de filtros entre páginas.
- Indicadores de faturamento, lucro e quantidade vendida.
- Botões interativos com indicadores (bookmarks).
- Gráficos de barras, pizza e mapas.
